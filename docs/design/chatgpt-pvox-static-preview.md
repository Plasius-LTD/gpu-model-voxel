# ChatGPT PVOX static preview

This package implements the format portion of
[site Story #2094](https://github.com/Plasius-LTD/plasius-ltd-site/issues/2094).
It accepts only compiler input extracted from a verified canonical model
document, emits a real content-addressed PVOX artifact, and renders review
evidence from that artifact. Hosted file intake, rights decisions, confirmation,
publication, and GPU Demo discovery remain owned by their respective services.

The demonstration compiler is deliberately closed to
`plasius.gpu-model-static-demo/1`: one 64³-or-smaller shell grid, at most 512
bricks and 262,144 occupied samples, and a minimally paged artifact no larger
than 4,521,984 bytes. Validation checks all spatial and hierarchy relations on
self-consistent bytes before review rendering or disposable-cache derivation.
